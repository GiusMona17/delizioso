# Delizioso V1.2 Implementation Plan & Ticket Map

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Delizioso v1.2 featuring expanded component categories with visual grouping, in-place responsive URL import loading UX, meal planner side items, and a dedicated Smart Home dashboard with updated 5-tab navigation.

**Architecture:** 
1. Grouped category domain models in `Categories.kt` with string resources.
2. In-place card state transitions in `ImportScreen.kt` driven by `ImportViewModel` state flow.
3. Multi-recipe slot support in `PlannedMealDao` and `PlannerViewModel` for linking sides and sauces.
4. `HomeViewModel` and `HomeScreen` aggregating today's planned meals, smart recommendations, quick actions, and favorites.
5. Streamlined 5-tab floating dock in `DeliziosoNav.kt`.

**Tech Stack:** Kotlin 2.1, Jetpack Compose, Material 3, Room 2.7, DataStore, JUnit 4, Kotlinx Coroutines.

**Spec:** [`docs/superpowers/specs/2026-08-21-delizioso-v1-2-design.md`](file:///d:/Projects/Coding/delizioso/docs/superpowers/specs/2026-08-21-delizioso-v1-2-design.md)

## Global Constraints

- **Language & JVM:** Kotlin 2.1, JVM 17.
- **UI Design System:** Custom Clay neumorphic components (`ClayTopBar`, `ClayCard`, `ClayButton`, `ClaySectionHeader`, `ClayFloatingButton`, `PillShape`, `ClayShadow`).
- **Persistence:** Room 2.7 migrations (if entity columns change).
- **Localization:** All user-facing strings must be defined in both `values/strings.xml` and `values-it/strings.xml`.
